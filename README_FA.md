# پوکو — نسخهٔ آزمایشی ۱.۰.۳

برنامهٔ اندرویدی آزمایشی برای گوشی‌هایی با Android 8 به بالا؛ هدف آزمایش اولیه POCO X3 Pro با Android 12 و MIUI 13 است.

## قابلیت‌های موجود در کد
- دریافت فقط اعلان‌های دو بستهٔ شناخته‌شدهٔ تلگرام؛ برنامه مستقیماً وارد حساب تلگرام نمی‌شود.
- نگهداری حداکثر ۳۰ اعلان اخیر با AES-GCM و کلید Android Keystore.
- نگهداری حداکثر ۱۰۰ پیام تاریخچهٔ گفت‌وگو با AES-GCM و Android Keystore.
- ذخیرهٔ نشانی HTTPS و توکن دستگاه به‌صورت رمزگذاری‌شده.
- پل ارتباطیِ قابل شروع و توقف دستی؛ پس از تنظیم سرور، heartbeat و دریافت پاکت فرمان را انجام می‌دهد.
- توقف دریافت فرمان‌های بعدی تا تعیین تکلیف فرمان قبلی و امکان رد محلی فرمان در انتظار.
- فرمان‌ها در این نسخه اجرا نمی‌شوند؛ رد کردن فرمان فقط نتیجهٔ رد را به سرور گزارش می‌کند.

## مرزهای امنیتی و محدودیت‌ها
- دسترسی اعلان فقط با فعال‌سازی صریح کاربر در تنظیمات Android ممکن است. خاموش بودن پیش‌نمایش اعلان می‌تواند متن پیام را پنهان کند.
- متن اعلان‌ها توسط کد ذخیره‌سازی به سرور ارسال نمی‌شود.
- هنگام استفاده از گفت‌وگوی آنلاین، حداکثر ۲۰ پیام اخیر برای سرور تنظیم‌شده فرستاده می‌شود.
- اتصال هوش آنلاین به Worker مستقرشده و کلید API نیاز دارد؛ هزینهٔ API جدا از اشتراک ChatGPT محاسبه می‌شود.
- میکروفون، دوربین، پیامک، مخاطبان، Accessibility و اجرای خودکار فرمان‌ها در این نسخه وجود ندارند.
- برنامه روی گوشی واقعی هنوز باید نصب و آزمایش شود؛ موفقیت ساخت APK به‌تنهایی تضمین عملکرد روی MIUI نیست.

## ساخت APK
گردش‌کار GitHub Actions با نام `Build Poco Assistant APK` پس از هر تغییر در شاخه `main` اجرا می‌شود. APK از بخش Artifacts اجرای موفق قابل دریافت است.
