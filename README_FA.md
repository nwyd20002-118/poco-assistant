# پوکو — نسخه آزمایشی ۰٫۱

## هدف این مرحله
این نسخه فقط یک پل محلی و محدود برای دریافت اعلان‌های تلگرام است. هنوز دستیار هوش مصنوعی کامل نیست.

## سازگاری هدف
- دستگاه هدف: POCO X3 Pro
- سیستم هدف: Android 12 / MIUI 13
- بدون روت
- حداقل Android: API 26
- زبان پیاده‌سازی: Java
- ساخت APK: GitHub Actions در فضای ابری؛ بنابراین کامپیوتر شخصی لازم نیست.

## محدوده و حریم خصوصی
- برنامه فقط اعلان‌های بسته‌های `org.telegram.messenger` و `org.thunderdog.challegram` را در کد پردازش می‌کند.
- حداکثر ۳۰ اعلان اخیر در SharedPreferences خصوصی برنامه ذخیره می‌شوند.
- مجوز `INTERNET` تعریف نشده است؛ این نسخه هیچ اتصال شبکه‌ای ندارد.
- مجوز میکروفون، مخاطبان، پیامک، فایل‌ها یا Accessibility تعریف نشده است.
- `allowBackup=false` است تا داده‌های برنامه در پشتیبان‌گیری اندروید قرار نگیرند.
- مجوز Notification Access را خود کاربر باید در تنظیمات اندروید فعال کند. این مجوز در سطح سیستم حساس است؛ فقط وقتی فعالش کن که منبع APK و کد را بررسی کرده باشی.

## محدودیت‌ها
- فقط متن‌هایی دیده می‌شوند که خود تلگرام در اعلان نمایش می‌دهد. اگر پیش‌نمایش پیام در تلگرام خاموش باشد، ممکن است متن خالی باشد.
- این نسخه پیام ارسال نمی‌کند و به رابط کاربری تلگرام دست نمی‌زند.
- پاسخ سریع از اعلان (RemoteInput) در مرحله بعد و فقط پس از بررسی سازگاری اعلان تلگرام اضافه می‌شود.
- دسترسی‌پذیری عمداً اضافه نشده است؛ این مجوز گسترده است و فعلاً لازم نیست.
- فعال‌سازی صوتی دائمی، مدل هوش مصنوعی و API پولی هنوز وجود ندارند.
- MIUI ممکن است سرویس‌های پس‌زمینه را محدود کند؛ پایداری واقعی باید روی خود گوشی آزمایش شود.

## ساخت APK بدون کامپیوتر
این پروژه فایل workflow آماده دارد:
`.github/workflows/build-apk.yml`

روش ساخت:
1. در مرورگر گوشی وارد GitHub شو و یک مخزن **Public** خالی با نام `poco-assistant` بساز. برای رایگان ماندن ساخت‌های GitHub Actions، مخزن عمومی انتخاب شده است. هیچ پیام، شماره، رمز یا کلید API را داخل مخزن قرار نده.
2. محتوای این پروژه را در ریشه مخزن قرار بده، از جمله پوشه مخفی `.github/workflows`.
3. با ثبت فایل‌ها روی شاخه `main`، فرایند ساخت خودکار اجرا می‌شود. یا از تب Actions، workflow با نام `Build Poco Assistant APK` را دستی اجرا کن.
4. پس از موفقیت، در صفحه اجرای workflow بخش Artifacts فایل `poco-assistant-debug-apk` را دریافت کن؛ داخل آن `app-debug.apk` است.
