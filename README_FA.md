# پوکو — نسخه آزمایشی ۰٫۱

این پروژه یک برنامه اندرویدی آزمایشی برای POCO X3 Pro و Android 12 است.

## قابلیت فعلی
- خواندن اعلان‌های نمایش‌داده‌شده از دو بسته شناخته‌شده تلگرام.
- نگهداری حداکثر ۳۰ اعلان اخیر در فضای خصوصی برنامه.
- نمایش اعلان‌های ذخیره‌شده و پاک‌کردن آن‌ها از داخل برنامه.
- فعال‌سازی دسترسی اعلان فقط با اقدام صریح کاربر در تنظیمات اندروید.

## محدودیت‌ها
این نسخه پیام‌های داخل تلگرام را مستقیماً نمی‌خواند؛ فقط متن موجود در اعلان‌ها را می‌بیند. اگر پیش‌نمایش اعلان خاموش باشد، ممکن است متن پیام در دسترس نباشد. ارسال یا پاسخ‌دادن به پیام، اینترنت، میکروفون، مخاطبان، پیامک، Accessibility و اتصال به مدل هوش مصنوعی در این نسخه وجود ندارد.

## ساخت APK
در GitHub Actions، گردش‌کار `Build Poco Assistant APK` پس از push به شاخه main اجرا می‌شود یا می‌توان آن را دستی از بخش Actions اجرا کرد. فایل APK آزمایشی در بخش Artifacts همان اجرای موفق قرار می‌گیرد.

## مشخصات ساخت
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Java 17
- compileSdk 35
- minSdk 26
